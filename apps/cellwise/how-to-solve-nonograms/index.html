How to solve nonograms, step by step

How to solve nonograms step by step: what the clues mean, the overlap rule, crossing out squares, and a full 5×5 puzzle solved line by line.

Updated 26 Nov 20265 min read

To solve a nonogram, read each clue as a list of filled runs in order, with at least one empty square between runs. Start with the lines where the clues leave little room, fill the squares that must be filled wherever the runs sit, cross out the squares that cannot be filled, then use each new square to unlock the crossing line. Repeat until the picture is complete.

Nonogram rules in one minute

  • The grid starts blank. Each row has a clue on its left and each column has a clue above it.
  • A clue like 3 1 means: a run of 3 filled squares, then a gap of one or more empty squares, then a run of 1. The order of the numbers is the order of the runs, left to right or top to bottom.
  • A clue of 0 (or an empty clue) means the whole line is empty.
  • Every square ends up either filled or empty. Mark the empty ones with an X so you can see what you have proved.
  • A well-made puzzle has exactly one picture that fits every clue.

That is all. There is no arithmetic beyond adding small numbers, and no word knowledge.

The first move: lines that fill themselves

Add up the clue numbers, then add one for each gap between runs. If the total equals the line length, the line has only one arrangement. In a 5-wide row, the clue 5 fills every square, and 2 2 gives filled, filled, empty, filled, filled (2 + 1 + 2 = 5). Look for these first in any puzzle.

The overlap rule

Most lines are not that tight, but big runs still give squares away. Picture the run pushed as far left as it can go, then as far right. The squares covered in both positions must be filled.

Take a 10-wide row with the clue 7. Pushed left, the run covers squares 1 to 7. Pushed right, it covers squares 4 to 10. Squares 4, 5, 6 and 7 are filled in both, so fill them now.

A quick way to do this in your head: work out the slack, which is the line length minus (the clue total plus the gaps). Any run longer than the slack gives you (run length minus slack) filled squares. For the clue 7 in 10, slack is 3, so the run gives 7 minus 3 = 4 squares. With several runs, each run only moves within its own slack: in a 15-wide row with 4 3 5, the total is 4 + 3 + 5 + 2 gaps = 14, slack is 1, and you can fill 3 squares of the 4, 2 of the 3 and 4 of the 5.

A worked 5×5 nonogram

  1. Row 3 (clue 5) fills all five squares.
  2. Rows 4 and 5 (clue 2 2) each have exactly one arrangement: filled, filled, empty, filled, filled.
  3. Column 1 (clue 3) now has squares 3, 4 and 5 filled. That is its whole run, so cross out squares 1 and 2. Column 5 is the same.
  4. Column 2 (clue 4) has squares 3, 4 and 5 filled and needs one more square in the same run. Square 2 is the only one that touches the run, so fill it and cross out square 1. Column 4 is the same.
  5. Column 3 (clue 3) has square 3 filled and squares 4 and 5 crossed out (from step 2). A run of 3 that ends at square 3 must cover squares 1, 2 and 3. Fill them.
  6. Check the rows: row 1 now has one filled square (the middle), row 2 has three. Both match their clues.

It is a house. Notice that no step needed a guess: each one followed from a clue plus squares already proved. That is how every good nonogram works, only with more steps.

Crossing out matters as much as filling

Beginners often fill squares and leave the rest blank. An X is information too. In step 5 above, the crossed squares at the bottom of column 3 are what forced the run upward. Whenever a line's runs are all placed, cross out everything else in it at once.

Useful habits from the start

  • Work in passes. Go through every row, then every column, then repeat. Each pass uses what the previous one proved.
  • Start from the big numbers. A clue close to the line length gives the most squares.
  • Use the edges. If the first square of a line is filled, the first run starts there, so you can fill its full length and put an X after it.
  • Count from both ends. A run near the edge often can only reach so far, which proves the squares beyond it empty.
  • Never fill on a hunch. If you are unsure, leave the square blank and move to another line. On a well-made puzzle, another line always has a move.

When you get stuck

Stuck usually means a step was missed, not that the puzzle needs a guess. Go back to each line that changed recently and ask two questions: which squares must now be filled, and which can no longer be reached by any run? Questions

How do you start a nonogram?

Add each clue's numbers plus one per gap. Lines where that total equals the length, or comes close, give you squares right away. Fill those first, then work the crossing lines.

Do you have to guess in a nonogram?

Not in a well-made one. A good nonogram has one solution and can be finished by row and column logic alone. Some published puzzles do need a guess at one point; that is a flaw in the puzzle.

What does an X mean in a nonogram?

An X marks a square you have proved empty. Marking empties is as useful as filling squares, because it limits where the remaining runs can go.

How long does a nonogram take to solve?

A 5×5 takes a minute or two. A 10×10 usually takes a few minutes, and a 20×20 can take half an hour or more, depending on how many steps need two lines at once.
