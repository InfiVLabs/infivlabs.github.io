Nonogram tips and advanced techniques for when you're stuck

Nonogram tips for hard puzzles: edge forcing, reach, joining and splitting runs, color rules and a checklist for 15×15 and 20×20 grids when you're stuck.

Updated 26 Nov 20266 min read

When a nonogram stalls, the next move is almost always hiding in a line you already touched. The techniques below find it: forcing runs from the edges, ruling out squares no run can reach, joining and splitting filled squares, and closing finished runs with an X. Each comes with a small example on a 10-square line, so you can check it with a pencil.

If the basic rules and the overlap method are new to you, read how to solve nonograms first.

1. Slack: the number that tells you where to look

Slack is the line length minus the clue total minus the gaps between runs. A 10-square line with 3 4 has a total of 3 + 4 + 1 gap = 8, so the slack is 2. Every run longer than 2 gives you squares: the 3 gives 1 and the 4 gives 2. When you are stuck, recompute slack for lines that have changed. A crossed-out square at the edge shrinks a line, which shrinks its slack and can turn a dead line into a productive one.

2. Edge forcing

A filled square near the edge belongs to the first run if no other run can reach it. Then the run must stretch far enough to include it.

Example: 10 squares, clue 4 2, square 2 is filled. The second run can start no earlier than square 6, so square 2 belongs to the 4. Whether the 4 starts at square 1 or 2, it covers squares 2, 3 and 4. Fill 3 and 4.

The same works from the right end and from any X that acts like a wall.

3. Reach: squares no run can touch

Once a run is anchored by a filled square, it can only stretch so far.

Example: 10 squares, clue 3, square 5 is filled. The 3 must include square 5, so it lies somewhere in squares 3 to 7. Squares 1, 2, 8, 9 and 10 can never be filled. Cross them out. On big grids, reach is the technique that clears the most empty space.

4. Joining and splitting

Two filled squares in the same line either belong to one run or to two.

  • Joining: 10 squares, clue 5, squares 3 and 6 filled. Only one run exists, so it covers both, and squares 4 and 5 are filled. The run of 5 must then start at square 2 or 3, so squares 1, 8, 9 and 10 are empty.
  • Splitting: 10 squares, clue 2 2, squares 3 and 6 filled. No run of 2 can cover both, so square 3 belongs to the first run and square 6 to the second. The first run then lies within squares 2 to 4 and the second within squares 5 to 7, so squares 1, 8, 9 and 10 are empty.

5. Finished runs get two X marks

When a filled stretch reaches the length of the largest run that could be there, it is complete. Put an X on both ends. Example: clue 1 3 1, and you find three filled squares in a row in the middle. No other run is longer than 1, so that stretch is the 3. Cap it at both ends, and the 1s must sit outside the caps.

6. Gaps too small for any run

An X splits a line into separate spaces. Any space shorter than the smallest run that could go there must be empty.

Example: clue 3 3, square 3 is crossed out. Squares 1 and 2 form a space of 2, too short for a 3. Cross them out too. This often cascades: the new X marks change the slack of the crossing columns.

7. Color nonogram rules

In color nonograms, each run has a color. Runs of the same color still need a gap, but runs of different colors may touch. That changes the arithmetic: a 5-square row with red 2, blue 2 has a total of only 4 (no gap needed), so the slack is 1, and each run gives one sure square (red on square 2, blue on square 4). In black and white, 2 2 in 5 squares would fill the whole line. Color also helps: a filled square's color tells you exactly which run it belongs to, so edge forcing and reach work faster.

8. "What if" across two lines

When single lines give nothing, test one square: suppose it is filled, follow the consequences in its row and column, and see if any line breaks. If it does, the square is empty. If nothing breaks, erase the test marks. This is still logic, as explained in nonograms without guessing, and on a well-made puzzle you will rarely need it.

Tips for 15×15 and 20×20 nonograms

  • Work in full passes. Do every row, then every column, then start again. Do not chase one corner; a square proved in row 14 may unlock column 3.
  • Use the thick lines. Grids are usually drawn with a heavier line every 5 squares. Count in fives instead of square by square, and you will make fewer counting mistakes.
  • Start with clues close to the line length. On a 20-wide row, a clue like 6 5 6 (total 19) leaves a slack of 1 and fills 14 squares at once.
  • Cross out aggressively. On big grids, X marks are what shrink each line to something you can reason about.
  • Mark finished clues. Strike out each clue number once its run is placed. Your eye then goes only to the work left.
  • Take a short break. On a 20×20, coming back after five minutes often shows a move you looked straight past.

A checklist for when you're stuck

  1. Recompute slack for every line that changed in your last few moves.
  2. Check both edges of each line for a filled square near the end.
  3. Look for filled squares whose run cannot reach far: cross out everything beyond.
  4. Look for two filled squares in one line: join or split them.
  5. Cap every complete run with an X on both ends.
  6. Cross out spaces too small for any run.
  7. Only then try a "what if" test, and erase it if nothing breaks.

Questions

How do you solve hard nonograms?

Work in passes, recompute slack after each change, and use edge forcing, reach and joining. When single lines give nothing, test one square with a "what if" and keep only what you can prove.

What do you do when you're stuck on a nonogram?

Go back to the lines you changed most recently. Check their edges, their slack, any filled squares that limit a run's reach, and any spaces too small for a run.

Are color nonograms harder than black and white?

Usually they are a little easier per line, because each square's color tells you which run it belongs to. The catch is that runs of different colors can touch, so you cannot count on a gap.

How long does a 20×20 nonogram take?

Often 20 to 60 minutes, depending on how many steps need two lines at once. Puzzles with lots of empty space tend to go faster.
