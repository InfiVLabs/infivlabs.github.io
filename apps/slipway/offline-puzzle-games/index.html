Offline puzzle games: how to find ones that really work without wifi

Offline puzzle games for Android: which puzzle types work without wifi, what still needs a connection, and a five-minute airplane mode test.

Updated 26 Nov 20264 min read

Most logic puzzle games can work without wifi, because their puzzles are stored on your phone or generated by it. Sudoku, nonograms, arrow puzzles, sliding block puzzles and mahjong solitaire usually play fine offline. What often breaks without a connection is the extras: daily challenges downloaded from a server, events, cloud saves and leaderboards. The only reliable check is to try the game in airplane mode before you need it.

The pattern: the more a game's content comes from a server (fresh pictures, daily crosswords, live events), the less of it you get offline. Games that build their puzzles with an algorithm on the phone, as many arrow and number puzzles do, tend to be fully playable without a signal.

What usually needs a connection, even in offline games

  • Ads. Ads are downloaded when shown. Without a connection, most games simply skip them, but rewarded ads (watch an ad for a hint or a life) will not work either.
  • Daily puzzles from a server. Some games create the daily puzzle on the phone from the date; others download it. The second kind needs a connection.
  • Purchases and restores. Buying or restoring a purchase talks to the app store, so do it before you go offline.
  • Cloud saves and sign-in. Progress synced to an account may not save until you reconnect. Games that keep progress only on the device do not have this problem, but they also do not carry it to a new phone.
  • Events and leaderboards. Time-limited events and scores against other players need the server.
  • First launch downloads. Some games download extra content the first time you open them. Open a new game once on wifi before your trip.

The five-minute airplane mode test

Run this at home, before a flight or a long commute:

  1. Install the game and open it once while you are online. Play the first level.
  2. Turn on airplane mode. Also turn off wifi if your phone keeps it on in airplane mode.
  3. Close the game fully (swipe it away from recent apps), then open it again.
  4. Play three levels in a row. Note anything that fails to load.
  5. Try the daily puzzle, a hint and any locked or new level pack.
  6. Turn airplane mode off and check that your progress is still there.

If the game passes steps 3 to 6, it will work on a plane, in the underground or anywhere with no signal.

Reading the store listing before you install

The Google Play listing tells you some of this up front. A "Contains ads" label means the developer has declared ads in the app; it does not cover in-app purchases, which have their own label. The description often says whether the game plays offline, but test it anyway: a game can be "offline" for its main levels and still need a connection for dailies.

Choosing an offline puzzle game for adults

  • Untimed play. Calm puzzles without a clock are easier to pick up and put down on a commute.
  • Short rounds. If you play in gaps of a few minutes, a game with 1 to 3 minute boards fits better than one with 30 minute puzzles.
  • Progress on the device. For travel, that means it works anywhere. Back it up if the game offers an export.
  • Readable on a small screen. Look for zoom on large boards and big touch targets.
  • Battery. Simple 2D puzzle games are usually light on battery, and airplane mode saves more.

Arrow puzzles offline

Arrow puzzles suit offline play well: each board takes a minute or two, needs no reading, and can be built on the phone. If you have not played one, the rules take a minute to learn; our guide on how to solve arrow puzzles has a full example, and the arrow puzzle tips cover harder boards.

How Slipway handles offline play

Slipway generates every board on the phone, including the daily board, so it plays fully without wifi, with no account. Progress stays on your device, and the settings include a backup you can export. Ads and purchases need a connection like in any other game.

Questions

What puzzle games work without wifi?

Most logic puzzles that store or generate their puzzles on the phone: sudoku, nonograms, arrow puzzles, sliding block puzzles, mahjong solitaire and word search. Test each game in airplane mode to be sure.

How do I know if a game works offline?

Open it once online, then turn on airplane mode, restart the game and play a few levels, including the daily puzzle. If everything loads, it works offline.

Do offline games still show ads?

Ads need a connection to load, so most games show none while you are offline. They return when you reconnect.

Will I lose my progress if I play offline?

Not in games that save on the device. Games that sync progress to an account may only save it once you are back online, so check before a long trip.
