Wi-Fi hotspot multiplayer games on Android, and how to set them up

Wi-Fi hotspot multiplayer games on Android: how hotspot play works, setup steps, games that still support it, and fixes when friends can't join.

Updated 26 Nov 20264 min read

A Wi-Fi hotspot multiplayer game lets friends in the same room play together over a hotspot that one phone switches on. No router and no internet are needed: the phones talk to each other directly over the hotspot's local network. The catch is that the game has to support local or LAN play, and many games that once did have dropped it.

That is why so many "hotspot games" lists you find are years out of date. Before your group spends ten minutes setting up, check that the game still has a local mode in its current version.

How hotspot multiplayer works

When you switch on a hotspot, your phone becomes a small Wi-Fi router. Every phone that joins it is on the same local network, just like phones on one home Wi-Fi.

A game with local play then does two things:

  • One phone hosts. It opens a room and announces it on the network.
  • The others find the room in a list or join with a code, and from then on the game's data goes phone to phone.

That traffic never leaves the room, so the game itself doesn't use the host's mobile data. Google's Android help says a phone can share its connection with up to 10 other devices over a hotspot, so the hotspot is rarely the limit. The game's own player cap usually is.

Setting it up, step by step

  1. Update the game on every phone first, while you still have internet. Most local modes refuse to connect phones on different versions.
  2. Pick the host. Use the phone with the most battery: running a hotspot and hosting a game both drain it faster.
  3. Turn on the hotspot on the host phone (Settings, then Network or Connections, then Hotspot). Note the network name and password.
  4. Connect the other phones to that hotspot in their Wi-Fi settings. If a phone warns that the network has no internet and offers to switch to mobile data, choose to stay connected.
  5. Open the game on the host first and create the room or lobby.
  6. Join from the other phones through the game's local, LAN or "nearby" option.

If the room doesn't appear within half a minute, go to the fixes below before trying anything else.

When friends can't see your room

Most hotspot problems come down to one of these:

  • Different versions. One phone updated, another didn't. Update everyone and restart the game.
  • Phone left the hotspot. Android sometimes drops a Wi-Fi network with no internet and goes back to mobile data. Check each phone's Wi-Fi icon and reconnect.
  • The room is announced but not received. Some phones handle discovery on their own hotspot poorly. If the game offers it, join by the host's IP address or a room code instead of the list.
  • Battery saver on the host. Some phones turn the hotspot off when idle or in power saving. Plug the host in or switch saver off for the session.
  • Too many players. The game's cap counts the host. An 8-player game means the host plus seven friends.

Questions

Does hotspot multiplayer use mobile data?

The game traffic between phones stays on the hotspot's local network, so it doesn't count against anyone's data. A game may still try to load ads or check for updates over the internet if the host's mobile data is on. Switch mobile data off on the host if you want to be sure.

How many phones can join an Android hotspot?

Google's Android help says up to 10 other devices can share a phone's connection over a Wi-Fi hotspot. Some phone makers and carriers set their own limits, so check your phone's hotspot settings.

Can iPhones and Android phones play together over a hotspot?

Only if the game exists on both systems and its local mode allows mixing them. Many don't, so check the game's own help pages first.

Is Bluetooth multiplayer the same thing?

No. Bluetooth multiplayer is a separate feature that a game has to support on its own, and it usually allows fewer players. A game with hotspot play won't automatically work over Bluetooth.

Playing Fart Chaos over a hotspot

Fart Chaos is a party racing game where four critters on a round raft steer by farting. Over one Wi-Fi network or a phone hotspot:

  • QUICK MATCH puts phones on the same network into the same race, and bots fill any empty seats.
  • LOCAL TEAM opens a room that friends join with a four-letter code; up to 8 players share four rafts.
  • If a network blocks room discovery, friends can join by the host's IP address, shown in the host's room.
